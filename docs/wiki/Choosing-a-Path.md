# Choose a Path

Use this page when you know the work you need to support but are unsure which part of AgentManufacturing to open first.

## Pick the smallest useful package

| Package | Use it when | What it gives you |
| --- | --- | --- |
| **Atomic skill** | You need one bounded method, such as takt-time calculation or a DFM review | A focused workflow with inputs, steps, outputs, and review boundaries |
| **Professional skillset** | A role needs a repeatable group of related workflows | A curated composition for one professional role |
| **Jurisdiction overlay** | Canadian law, standards, or regulatory context affects the work | Jurisdiction-specific constraints kept separate from generic methods |
| **Sector specialization** | The work concerns a named manufacturing sector | Sector requirements and source expectations |
| **Validation package** | You are changing, publishing, or relying on the repository | Structural checks, routing scenarios, and release-readiness evidence |

## Common combinations

- **General manufacturing review:** choose an atomic skill, then confirm evidence and qualified-review requirements.
- **Canadian regulated work:** choose the atomic skill, add the relevant [jurisdiction and safety](Jurisdiction-and-Safety) overlay, and verify current sources.
- **Role-based delivery:** start with [Professional Skillsets](Professional-Skillsets), then follow its linked atomic workflows.
- **Sector-specific work:** use [Sector Specializations](Sector-Specializations) to identify added requirements before selecting a skill.
- **Repository change:** read [Contributing and Maintenance](Contributing-and-Maintenance), update the relevant package metadata, and run the full validator.

## What a path does not do

Path selection does not prove applicability, create an approval, or replace engineering, safety, legal, or other qualified review. Role resolution lists references; it does not execute them.
