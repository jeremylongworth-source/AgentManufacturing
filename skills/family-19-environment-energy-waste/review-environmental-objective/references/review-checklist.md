# Review objective measurability

- An absolute consumption target and an intensity target answer different questions. Require the definition and output population before comparison.
- A voluntary target does not discharge a legal obligation. Record supplied obligation sources and their scope without deciding applicability.
- The review assesses measurability only; achieving a target requires a separate measured-result assessment.

## Source boundary

Record source ID, date, applicable scope, revision, claim location, and verification status. No source is assumed applicable from its title alone. For AM-25's bounded catalogue and government-guidance checks, see the repository [source evidence](../../../../docs/development/AM-25-source-evidence.md). Package methods remain usable with supplied evidence if this repository-level context is absent; a dependent source claim must await verification.
