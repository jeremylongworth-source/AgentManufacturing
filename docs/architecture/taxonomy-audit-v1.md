## Resolution of the AM-02 audit queue

1. **Every-candidate review:** all 162 records have eight-dimensional evidence, a disposition, an accepted target, and a concrete future scenario. No record is accepted solely because its fields exist.
2. **Broad outputs and orchestration:** production planning produces one horizon allocation; root-cause analysis adjudicates hypotheses for one problem; KPI analysis compares defined measures; engineering-change impact produces one affected-responsibility matrix. Their bodies must not grow into autonomous execution of all contributing disciplines. Smaller evidence-producing methods remain separately reusable. The five AM-10 reference names remain accepted.
3. **Inspection/measurement overlap:** merge the three parameter-only supplier variants described above. Retain certificate review for document identity/claims, supplier qualification for organizational capability, and supplier-defect analysis for mode/attribution evidence. Measurement method, instrument fitness, study analysis, calibration status, traceability, and custody each answer a different question; their scenario outcomes specify the distinction.
4. **Dependencies:** replace the seven-edge draft view with 76 named evidence-reuse edges and a topological order. Equivalent supplied evidence is explicit. Generic root-cause and impact assessments do not require every possible subordinate method. No core-to-overlay edge or cycle is accepted.
5. **Safety/jurisdiction metadata:** retain conservative baseline classes and conditional flags with an explicit pending-formalization status. They identify questions and review limits, not legal applicability. AM-04/05 must formalize mechanics and amend records where needed; these planned refinements do not leave catalogue ownership unresolved.
6. **Safety-topic coverage:** the matrix below assigns recognition/review handoffs for all nine AM-05 gate topics. Do not add nominal specialist skills without distinct authorized inputs/outputs. Specialist operational program evaluation beyond these accepted boundaries requires a later explicit scope decision.
7. **Reference evidence/scenarios:** the index preserves the five P0 records, each with a discriminating scenario and `SPECIFIED_NOT_EXECUTED` status. AM-06/09 must turn these into package and behavior checks; no fixture presence is represented as an executed model test.
8. **Freeze artifacts:** v1 taxonomy, dependency map, canonical YAML index, this audit, validator, and handoff are provided. AM-02 remains preserved as draft history.
