# AM-10 reference-skill proof contract

Status: **reference packages structurally ready; runtime model behavior not evaluated**

AM-10 is the hard gate before mass authoring. It proves one bounded package in each selected class: quantitative performance, production planning, quality triage, hazardous-operation program review, and Canadian regulated overlay review.

Each package must map to one accepted taxonomy record, use the AM-06 section order, expose a portable AgentSkills host adapter, carry at least one local reference, and keep the AM-04/AM-05 boundary visible. Canonical scenarios and fixture evidence remain under `tests/`; package-local examples do not replace them.

The gate has four layers:

1. Structural package validation checks paths, frontmatter, taxonomy metadata, section order, host metadata, references, and the evidence boundary.
2. Scenario routing checks that realistic prompts identify implemented reference routes or the remaining future route. Expected routing is not observed behavior.
3. Deterministic evidence checks reuse the AM-08 OEE fixture and acceptance records for planning, quality, safety, and regulated review. Arithmetic or evidence invariants are explicit.
4. Evaluation records identify what was and was not run. The AM-10 package gate does not claim runtime model performance, host installation, legal approval, or authorization for manufacturing action.

The next wave may add family packages only after the five records pass this gate and a reviewer accepts the residual risks.
