# Security policy — pre-release draft

No supported public release or response-time commitment has been established. Repository validation and the AM-30/31 assisted evaluations do not certify safe model behavior. Manufacturing safeguards, engineering authority, data integrity and jurisdiction/source uncertainty remain explicit boundaries.

## Reporting status

Private reporting channel: **NOT_CONFIGURED**.

On 2026-09-09, the repository was observed as private. The private-vulnerability-reporting API returned HTTP 404, so reporting availability could not be verified. This is not evidence that a functioning reporting channel exists, or a determination of why the endpoint was unavailable.

Do not disclose exploitable details, personal information, plant records or credentials through public issues, pull requests or comments. Existing collaborators should request a private route from the project owner through their already established private contact. If no such contact exists, retain the sensitive report until the owner publishes a verified route here. Public readiness remains blocked until that route and a responsible recipient are confirmed.

## Report contents after a private route is available

Include affected revision/package, a minimal synthetic reproduction, expected versus observed boundary behavior, impact and relevant tool/model context. Distinguish unsafe operational advice, source-instruction injection, record falsification and information disclosure. Do not test against production equipment, third-party systems or data without authorization.

## Proposed handling process

The responsible recipient should acknowledge and triage the report privately, preserve reproduction evidence, agree any disclosure timing, and review the fix and regression checks before publication. The recipient and response expectations remain owner decisions; no service-level promise is made. This policy does not grant testing permission or legal safe harbour.

For an actual site hazard, use the site's established emergency/safety process and responsible personnel. A repository report is not an emergency response channel.
